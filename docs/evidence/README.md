# Local experiment output

The demo writes a new timestamped folder here for each run. These folders are
ignored by Git because raw records can include device identifiers, addresses,
and local paths. Review and redact a copy before publishing a measurement.

Older raw experiments and sponsor material remain in the private development
repo. They have not been deleted or rewritten. The public summary distinguishes
[earlier hardware results](../STATUS.md) from [fresh offline checks](../TEST_RESULTS.md).

Keep the original failed runs too. A simulation result should not be labeled as
physical validation, and a successful new run does not erase an earlier failure.
